# Former Schools of Virginia

This website aims to contain all of the sources of information on past, closed down schools here in Virginia. Each school will have a text description and depending on what's available they may also have images and locations! Go check us out today at <https://school.nathanc.me/>!

## Features

Admin accounts can invite other admin accounts, manage the counties, manage the schools, and manage the submissions from users trying to submit information.

## Technology

This website was made using Astro and we are using Drizzle and PostgreSQL as our database.
